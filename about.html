About Us

This project focuses on the development of a Smart Home Automation and Security System designed to improve safety, convenience, and efficiency in modern homes.

The system provides an integrated solution for monitoring and controlling home environments while enhancing security. The system is desined by Fanelo, Bridget , Soso and Maambele.

Our Features

  • Smart Lighting Control
  • Motion Detection
  • Security Monitoring
  • Temperature Monitoring
  • Distance Detection

Technology Used

Built using ESP32, sensors, and a web-based interface.
