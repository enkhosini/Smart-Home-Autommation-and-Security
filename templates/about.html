About Us

This project focuses on the development of a Smart Home Automation and Security System designed to improve safety, convenience, and efficiency in modern homes.

The system provides an integrated IoT solution for monitoring and controlling home environments using sensors and a web dashboard. It is designed by Fanelo, Bridget, Soso, and Maambele.

Our Features

  • Smart Lighting Control
  • Motion Detection (PIR Sensor)
  • Security Camera Monitoring
  • Temperature Monitoring (DHT22)
  • Distance Measurement (Ultrasonic Sensor)
  • Light Intensity Detection (LDR)

Technology Used

Built using ESP32 microcontrollers, IoT sensors, and a Flask-based web interface for real-time monitoring and control.
